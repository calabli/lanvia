# Lanvia

**简体中文** | [English](README.en.md)

局域网内多台设备（Mac / Windows / Linux / iPhone / iPad / 安卓）即时共享剪贴板和文件。不需要服务器、外网或账号。

- **电脑**：运行一个单文件程序，自动监听系统剪贴板；收到的内容直接写入剪贴板，⌘V / Ctrl+V 即可粘贴。
- **手机 / 平板**：不用安装，相机扫码后用浏览器打开（可“添加到主屏幕”）。
- **多台电脑**：使用同一个配对码，通过 UDP 广播自动发现并互相同步；内容在设备之间用 AES-256-GCM 加密传输。

## 主要功能

- 文字、图片、文件、文件夹即时互传；文件在后台多机备份，发送方关机也能下载
- 主动复制 / 主动粘贴两个独立开关、暂停同步、应用黑名单；密码管理器里的内容不会发送
- 搜索（多关键词、模糊匹配、标签、筛选）、代码高亮预览、编辑与历史版本、收藏片段、标签、评论、共享清单
- 单条保留时长、全局保留时间、批量删除、文件占用上限
- 桌面客户端：托盘快捷面板、悬浮预览、系统通知、送达回执、自动更新
- iOS 快捷指令 / 安卓自动化 HTTP 接口

完整功能说明见 **[产品文档](docs/PRODUCT.md)**（英文）。

## 下载与运行

**桌面客户端（推荐）**：从 Releases 下载。

- Mac：按芯片下载 `Lanvia-macos-apple-silicon.dmg` 或 `Lanvia-macos-intel.dmg`，双击里面的“安装 Lanvia.pkg”。目前未经 Apple 公证，首次打开需在“系统设置 → 隐私与安全性”里放行（详见 DMG 内的安装说明）。
- Windows：直接运行 `Lanvia-windows-amd64.exe`（ARM 设备用 `arm64`）。

桌面版常驻菜单栏 / 托盘：点图标弹出快捷面板（打字搜索、↑↓ 选择、回车复制），右键打开菜单。第一次启动会打开主窗口，用手机扫码即可配对。

**命令行版**：适合服务器、Linux 或不需要界面的场景。

```bash
go run ./cmd/lanvia
```

终端会打印配对码、局域网地址和二维码；浏览器打开 `http://localhost:8686` 是同样的管理页面。常用参数：

| 参数 | 说明 |
| --- | --- |
| `--join XXXXX-XXXXX` | 使用另一台电脑的配对码，加入它的空间 |
| `--peer 192.168.1.20:8686` | 手动指定对端（仅本次运行），路由器屏蔽广播或跨网段时使用，可重复 |
| `--no-discovery` | 不使用局域网广播，只连接手动添加的设备 |
| `--name 书房电脑` | 设备名 |
| `--port 8686` | HTTP 端口（广播固定使用 UDP 8687） |
| `--no-watch` | 不监听本机剪贴板 |
| `--lang en` | 终端输出和日志的语言（`zh` / `en`），默认跟随系统 |
| `--data DIR` | 数据目录，默认在系统配置目录下的 `Lanvia/` |

> 命令行版和桌面版不要同时运行，它们共用配置和端口。

**找不到对方时**：配对码相同但一直不显示对方（路由器屏蔽广播、不在同一网段等），在设置的“手动添加设备”里填对方 IP 即可，只需在一台电脑上添加。
