# Lanvia

局域网内多台设备（Mac / Windows / Linux / iPhone / iPad / 安卓）即时共享剪贴板和文件。

- **电脑**：运行一个单文件程序，自动监听系统剪贴板，收到的内容直接写入剪贴板，⌘V / Ctrl+V 即可粘贴。
- **手机 / 平板**：不用安装，相机扫码后用浏览器打开（可“添加到主屏幕”）。
- **多台电脑**：使用同一个配对码后通过 UDP 广播自动发现并互相同步，不需要服务器，也不需要外网。

## 下载与运行

**桌面客户端（推荐）**：Mac 解压 `Lanvia-macos.zip` 后把 `Lanvia.app` 拖进“应用程序”；Windows 直接运行 `Lanvia-windows-amd64.exe`。它常驻在菜单栏 / 托盘，不需要浏览器：

| 操作 | 作用 |
| --- | --- |
| 点托盘图标 | 弹出快捷面板：直接打字搜索，↑↓ 选择，回车写入剪贴板并收起，Esc 收起 |
| 右键托盘图标 | 最近 6 条内容一键复制（文件则保存并在访达/资源管理器中显示）、主动 / 被动模式、发送当前剪贴板、开机启动、退出 |
| 面板里按 **空格** 或 **⌘Y** | 悬浮预览窗口：长内容完整查看，回车复制全部，选中一段 ⌘C 只复制这段 |
| 面板里按 **⌘E**，或预览里点“编辑” | 修改内容，⌘S 保存为新版本，同步到所有设备 |
| 预览里点时钟按钮 | 历史版本：谁在什么时候改了什么，逐行对比，可复制或恢复任意版本 |
| 条目上的计时器按钮 | 这一条的保留时长：1 小时 / 1 天 / 7 天 / 30 天后删除、永久保留，同步到所有设备 |
| 托盘菜单 → 打开主窗口 | 配对二维码、设置（发送模式、历史保留时间、自动下载文件）、完整历史 |

**发送模式**：主动模式下复制即发送；被动模式下复制不发送，需要时从托盘菜单或页面上的“发送剪贴板”手动发送。在访达里复制的文件、密码管理器复制的密码都不会自动发送，文件请拖进窗口。

第一次启动会自动打开主窗口，方便手机扫码配对。关闭窗口不会退出，Lanvia 会继续在后台同步。

**命令行版**：适合服务器、Linux 或不想要界面的场景。

```bash
go run ./cmd/lanvia
```

终端会打印配对码、局域网地址和二维码；浏览器打开 `http://localhost:8686` 是同样的管理页面。命令行版和桌面版不要同时运行，它们共用配置和端口。

常用参数：

| 参数 | 说明 |
| --- | --- |
| `--join XXXXX-XXXXX` | 使用另一台电脑的配对码，加入它的空间（也可以在管理页面里操作） |
| `--peer 192.168.1.20:8686` | 手动指定对端。路由器屏蔽广播、开了 AP 隔离或跨网段时使用 |
| `--name 书房电脑` | 设备名 |
| `--port 8686` | HTTP 端口（广播固定使用 UDP 8687） |
| `--no-watch` | 不监听本机剪贴板 |
| `--data DIR` | 数据目录，默认在系统配置目录下的 `Lanvia/` |

## 打包

在 Mac 上执行，产物在 `dist/`：

```bash
scripts/build.sh
```

- `Lanvia-macos.zip`：通用二进制（Apple 芯片 + Intel）的 `Lanvia.app`，最低 macOS 13，临时签名
- `Lanvia-windows-{amd64,arm64}.exe`：带图标、高 DPI 清单、无控制台窗口（Windows 10/11 自带 WebView2）
- `lanvia-cli-*`：六个平台的命令行版
- `SHA256SUMS.txt`

`scripts/build.sh desktop` 或 `scripts/build.sh cli` 只打其中一部分。图标由 `go run ./tools/genicons` 生成。

## 目录


## 工作原理

```
 iPhone ─┐  SSE + HTTP                 签名 HTTP 转发
 iPad  ──┼──────────▶  Mac 节点  ◀──────────────────▶  Windows 节点 ◀── 安卓
         │                ▲                                   ▲
         └ 扫码配对        └──── UDP 广播发现 (8687) ──────────┘
```

- **节点**：每台电脑是一个对等节点（Go，网页资源打包进二进制）。桌面客户端把节点跑在同一个进程里，窗口加载它在 localhost 上提供的页面，所以和浏览器里看到的是同一套界面。
- **发现**：每 3 秒在各网卡上广播一个信标，里面带有由配对码派生出的空间 ID。发现同一空间的设备后，用签名请求访问它的 `/api/info` 来确认双方配对码一致。
- **同步**：每条内容有一个随机 ID。节点只转发自己第一次见到的变更，所以网络不需要全连通，也不会形成环路。新节点上线时会拉取对方的历史，删除和清空通过墓碑记录传播。
- **推送**：浏览器通过 Server-Sent Events 接收推送（iOS Safari 上很稳定，每 20 秒发一次保活），回到前台时自动重连。
- **文件**：上传到接收的节点，其他电脑在后台各自备份一份（默认 100 MB 以下，可在设置里调整），下载时先找发送方、不在线就找其他有副本的电脑，所以发送方关机也不影响。支持 Range（视频可以拖动进度条）。
- **保留时长**：全局保留时间只对本机生效，过期内容不会再从其他设备同步回来；单条的保留设置会同步到所有设备，同时修改时按时间取新、时间相同按固定规则决胜。
- **编辑与版本**：每次修改生成一个带编辑者和时间的版本，原始内容作为第一个版本保留。版本集合在节点间按 ID 求并集，当前内容取最新的版本，所以多台设备同时编辑也会收敛到同一结果，且不丢任何版本。
- **剪贴板**：macOS 用 `pbpaste`/`pbcopy`（强制使用 UTF-8），Windows 直接调用 Win32 API，并跳过被密码管理器标记为敏感的内容，Linux 用 `wl-clipboard`/`xclip`/`xsel`。远端写入的内容会被记住，不会被当成新复制的内容再广播一遍。

## 安全

- 配对码（10 位，约 50 bit）**从不在网络上传输**。两端都从它派生出 HMAC 密钥，每个请求用时间戳 + 方法 + 路径签名，有效期 5 分钟（客户端会先用 `/api/time` 校准时钟）。
- 二维码里的配对码放在 `#` 后面，不会发给服务器，读取后立即从地址栏移除。
- 局域网里是 http，浏览器没有 `crypto.subtle`，所以网页端自带了一份 SHA-256/HMAC 的实现（已验证与 Go 的结果一致）。
- 本机仪表盘不用签名，但要求请求来自回环地址、`Host` 是 localhost，并且写操作的 `Origin` 与 Host 一致，以此防 DNS rebinding 和跨站请求。
- 上传的文件返回时带 `Content-Security-Policy: sandbox`，SVG/HTML 一律作为下载附件，不能在本站执行脚本。
- **限制**：内容本身是明文 http 传输，同一 Wi-Fi 下能抓包的人可以看到内容（但拿不到配对码）。计划加入可选的 TLS 或端到端加密。

## 手机上的自动化（可选）

仪表盘“设置 → 自动化”里有一个 API 令牌（由配对码派生，不能反推出配对码）。

**iOS 快捷指令**：可以绑定到“轻点背面”或分享菜单。

- 发送剪贴板：`获取剪贴板` → `获取 URL 内容`（POST `http://电脑IP:8686/api/clip`，请求头 `Authorization: Bearer 令牌`，请求体为“文件”，内容选剪贴板）
- 取回最新内容：`获取 URL 内容`（GET `/api/latest`，带同样的请求头）→ `拷贝至剪贴板`

**安卓**：用 HTTP Shortcuts / Tasker 调用相同的接口。

## 网页端的能力边界

- 局域网的 http 页面不能在后台读取剪贴板，所以手机端需要手动粘贴（长按输入框），收到内容后点“复制”即可。电脑上的仪表盘（localhost）是安全上下文，可以一键粘贴。
- 截图或文件可以直接粘贴、拖拽或选择上传，有进度条。
- 会识别验证码和链接，提供“复制验证码”和“打开链接”按钮。
